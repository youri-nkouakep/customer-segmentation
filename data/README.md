# Data

UCI **Online Retail** dataset: 541,909 transactions of a UK-based online gift retailer, December 2010 to December 2011.
Chen, D. (2015), UCI Machine Learning Repository, https://doi.org/10.24432/C5BW33 (CC BY 4.0).

Run `python scripts/download_data.py` to save it as `data/raw/online_retail.csv`. The raw data is not versioned.
